# Calculatrice d'Intérêts Composés

Une calculatrice d’intérêt composé conçue pour une accessibilité maximale (niveau AAA), incluant le support complet des lecteurs d’écran (VoiceOver), une gestion optimisée des couleurs (contraste élevé et modes accessibles), une navigation sans JavaScript, des labels ARIA précis, et une expérience inclusive pour tous les utilisateurs.

---

## Présentation du projet

Cette application web permet de calculer facilement l’évolution d’un capital avec des intérêts composés. Elle est pensée et développée pour garantir une **accessibilité universelle** :

- **Support AAA** selon les critères WCAG (Web Content Accessibility Guidelines).
- Fonctionne avec ou sans JavaScript.
- Compatibilité optimale avec les lecteurs d’écran (VoiceOver, NVDA, JAWS...).
- Contrastes élevés et gestion de la perception des couleurs.
- Labels ARIA exhaustifs et structurés.
- Navigation clavier fluide et logique.
- Responsive et utilisable sur tous types d’appareils.

---

## Lancer le projet

1. **Pré-requis**
    - Un navigateur web moderne.

2. **Installation**

    - Cloner le dépôt :
      ```bash
      git clone https://github.com/heitzjulien/calculatrice-interets-composes.git
      cd calculatrice-interets-composes
      ```
    - Ouvrir simplement `index.html` dans votre navigateur.

3. **Utilisation**
    - Accédez à l’application via votre navigateur.
    - Remplissez les champs nécessaires (capital, taux, durée, etc.).
    - Lancez le calcul pour obtenir le résultat détaillé.

---

## Accessibilité : Points Respectés

- **Structure sémantique HTML** (titres, listes, balises `form`, etc.).
- **Labels ARIA** explicites pour tous les champs et boutons.
- **Navigation 100% clavier** (tabulation, navigation logique, focus visible).
- **Contrastes conformes AAA** (ratio > 7:1 partout).
- **Feedbacks accessibles** (messages de validation, erreurs lisibles par les lecteurs d’écran).
- **Support VoiceOver et autres lecteurs d’écran** vérifié.
- **Mode sans JavaScript** : toutes les fonctionnalités principales restent accessibles.
- **Gestion des couleurs** : vision daltonienne et contrastes adaptés.
